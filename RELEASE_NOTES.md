Предварительная версия **0.3.0** интеграции **PJLink with IR Wake**.

- Для Panasonic FW300NT и региональных вариантов FW300 добавлен выбор **Daylight View**: «Выключено», «Авто», «Включено».
- Режим читается с проектора через отдельное соединение Panasonic; команды с потерянным ответом не повторяются.
- Учитывается способ проекции: при задней проекции доступны два режима без «Авто», с соответствующей кодировкой Panasonic.
- Через «Настроить» можно изменить порт Panasonic (по умолчанию 1024), имя администратора веб-интерфейса и пароль либо отключить эту функцию. По умолчанию используются admin1 и пароль PJLink. В меню проектора должен быть включён NETWORK CONTROL.
- При сне, прогреве, охлаждении и недоступности Panasonic выбор режима недоступен. Основные объекты PJLink и ИК-пробуждение сохранены.
- Настройки Panasonic не требуют повторного обучения ИК. Диагностика отражает режим и безопасные ошибки соединения без учётных данных.

Обновите интеграцию через HACS с включёнными предварительными версиями и перезапустите Home Assistant. Повторное добавление проектора и обучение команд не требуются. Если Daylight View недоступен при включённом проекторе, проверьте настройки веб-доступа и порт Panasonic.

Daylight View корректирует изображение с учётом освещения; это не Normal/Eco мощности лампы. Сетевой протокол и интерфейс проверены эмулятором и настоящим HA; физический FW300NT требует проверки пользователем. Установка в действующий Home Assistant не выполнялась.
