# Panasonic Projector

Интеграция Home Assistant для проекторов Panasonic с PJLink, у которых в режиме ожидания отключается Ethernet. Включение из сна — через выбранный ИК-передатчик, основное управление — через PJLink. Для Panasonic FW300 добавлено управление Daylight View через протокол Panasonic. Настройка через интерфейс, без YAML.

## Возможности

- Автоматическое чтение производителя `INF1`, модели `INF2` и имени `NAME` при подключении. Неподдерживаемые поля не блокируют настройку.
- Включение и выключение, выбор входа, отключение звука через PJLink Class 1.
- Выбор любой сущности `remote` из списка. Проверен контракт вызовов Broadlink и пользовательской интеграции Xiaomi IR; фактическая поддержка других передатчиков зависит от их стандартных действий `remote.send_command` / `remote.learn_command`.
- Обучение команде включения во время настройки для передатчиков с поддержкой `LEARN_COMMAND`. Коды хранятся в интеграции передатчика. Повторное обучение доступно через «Перенастроить».
- Отдельный диагностический датчик связи PJLink; опрос каждые 30 секунд.
- Наработка и признак включения лампы по `LAMP`, с отдельными объектами для нескольких ламп, если они есть у проектора.
- Фаза питания: ожидание, включён, охлаждение и прогрев.
- Диагностика вентилятора, лампы, температуры, крышки, фильтра и прочих ошибок по `ERST`: «Норма», «Предупреждение», «Ошибка» и общий признак неисправности.
- Переключатель **AV Mute** (`AVMT 30/31`) и кнопка **Обновить данные**. Они не включают питание проектора.
- **Daylight View** для Panasonic FW300: выбор «Выключено», «Авто», «Включено» с чтением фактического режима.

### Два изображения рядом (Side by Side)

Кнопка **«Два изображения рядом»** отправляет команду Panasonic `ODW` один раз. В спецификации FW300 нет отдельного запроса состояния этой функции, поэтому объект реализован кнопкой без вымышленного состояния ВКЛ/ВЫКЛ. Сочетания входов и возможность вывода определяет проектор. Подтверждение ODW/OD1 принимается по двум строкам спецификации на странице 21; другие ответы считаются ошибкой. При потере ответа команда не повторяется.

### Дополнительные функции Panasonic

Для поддерживаемого FW300 создаётся **32 объекта** при одной лампе. Для других моделей остаются прежние 14 объектов PJLink.

| Объекты | Команды Panasonic |
|---|---|
| Температуры входящего и выходящего воздуха, °C | `QTM:0`, `QTM:1` |
| Наработка фильтра, часы | `QFI:0` |
| Число перемоток фильтра | `QFI:1` |
| Время после последней перемотки, часы | `QFI:4` |
| Расчётный остаток фильтра, часы | `QFI:5` |
| Громкость 0–63 | `QAV`, `AVL` |
| Яркость и контраст −32…+32 | `QVB`/`VBR`, `QVR`/`VCN` |
| Режим изображения | `QPM`, `VPM` |
| Цветовая температура | `QTE`, `OTE` |
| Формат изображения | `QS1`, `VS1` |
| Стоп-кадр | `QFZ`, `OFZ:0/1` |
| Автонастройка и цифровой масштаб | `OAS`, `DZU`, `DZD` |

Остаток фильтра — оценка самого проектора, зависящая от условий эксплуатации. Сброса счётчиков и принудительной перемотки интеграция не выполняет. Яркость и контраст регулируют изображение, а не мощность лампы. Доступность режимов изображения и формата зависит от входа и типа сигнала.

Все дополнительные функции используют настройки Panasonic, описанные ниже. Общий флажок «Дополнительное управление Panasonic» включает или отключает их вместе. Во время сна, прогрева и охлаждения эти объекты недоступны. Ошибка отдельной команды не скрывает остальные показания: например, отказ Daylight View без сигнала не мешает читать фильтр и громкость. Неизвестные значения не заменяются нулями. После управляющей команды выполняется чтение фактических значений.

Между командами Panasonic выдерживается пауза не менее 0,5 секунды. При сетевой ошибке или ошибке авторизации оставшаяся серия опроса прекращается; на весь дополнительный цикл отведено до 20 секунд. Ошибки ER401/ER402 содержат имя конкретной команды в query_errors. Отказы зависящих от сигнала команд проверяются снова при следующем опросе. Новые функции пока проверены эмулятором и настоящим API Home Assistant, а не физическим проектором.

### Panasonic Daylight View

На FW300NT и региональных вариантах семейства FW300 сущность появляется автоматически после обновления и перезапуска Home Assistant. Daylight View корректирует изображение с учётом освещения; это не переключатель мощности лампы Normal/Eco. При задней проекции доступны только «Выключено» и «Включено»; способ проекции читается командой QSP.

В меню проектора должен быть включён **NETWORK CONTROL**. Команды передаются на тот же адрес, отдельный порт Panasonic — по умолчанию **1024**. Если выбор режима недоступен при включённом проекторе, откройте **Настройки → Устройства и службы → Panasonic Projector → Настроить**. Укажите порт, имя администратора веб-интерфейса (обычно `admin1`) и его пароль. По умолчанию используется пароль PJLink. Пустой пароль допустим только при подключении без авторизации. Здесь же можно отключить управление Daylight View. Обучение ИК повторять не нужно.

При сне, прогреве, охлаждении или ошибке Panasonic выбор режима недоступен; остальные объекты PJLink продолжают работать. После команды режим читается с устройства. Команда с потерянным ответом не повторяется, ИК для Daylight View не используется. Ошибки отдельного соединения отражаются в диагностике `query_errors.daylight_view` без пароля или имени пользователя.

Команды `QVX:DLVI0` и `VXX:DLVI0=+00000/+00001/+00002` приведены в [спецификации FW300NT](https://eww.pavc.panasonic.co.jp/projector/extranet/main/spec/specfiles/fw300nt_sf.pdf). Подробный формат ответа `DLVI0=+00001`, кодировка при задней проекции и пауза минимум 0,5 секунды между командами — в [полной спецификации Panasonic FW300](https://www.audiogeneral.com/Panasonic/ptfw300u_rs232.pdf), страницы 2, 10, 33. Формат соединения NTCONTROL и MD5 авторизации — в [документации Panasonic](https://ap.connect.panasonic.com/sites/default/files/media/document/2024-04/rz575_manual_en_2.pdf). Сетевой обмен проверен программным эмулятором; работа Daylight View на физическом FW300NT требует проверки.

### Лампа и диагностика

«Наработка лампы» показывает фактический счётчик часов, полученный с проектора. PJLink Class 1 не передаёт точный остаток ресурса или процент износа лампы. Численная температура и часы фильтра через эти запросы тоже не доступны: `ERST` передаёт только предупреждения и ошибки. Сброс счётчика при замене лампы выполняется средствами проектора.

Когда Ethernet недоступен, текущие показания лампы, ошибки и AV Mute становятся недоступными. Ноль часов и «Норма» не подставляются. Ошибка отдельного диагностического запроса не отключает медиаплеер. Ответ `ERR1` помечает запрос как неподдерживаемый до перезагрузки интеграции; временные `ERR3` и ошибки разбора проверяются снова при следующем опросе.

Семантика новых запросов соответствует [документации Panasonic по PJLink](https://eww.pavc.panasonic.co.jp/projector/extranet/main/previous/LB3/LB3_Network/NT-EN.pdf). Чтение лампы и ошибок на физическом FW300NT ещё требует проверки; работа питания и ИК-пробуждения ранее подтверждена пользователем.

## Обновление до 1.0.0

Новое отображаемое имя — **Panasonic Projector** (прежнее — PJLink with IR Wake). Внутренний домен pjlink_ir, адрес репозитория, сохранённая запись, идентификаторы объектов и ИК-настройки сохранены. Обновите интеграцию через HACS и перезапустите Home Assistant; повторное добавление и обучение ИК не требуются. Релиз 1.0.0 обычный, показ предварительных выпусков не требуется.

## Установка через HACS

1. Откройте HACS → меню → «Пользовательские репозитории».
2. Добавьте `https://github.com/ipmerlin/ha-pjlink-ir`, категория **Integration**.
3. Установите **Panasonic Projector**.
4. Перезапустите Home Assistant и добавьте **Panasonic Projector** в «Настройки → Устройства и службы».

## Установка из архива

1. Скачайте `pjlink_ir-1.0.0.zip` со [страницы релиза](https://github.com/ipmerlin/ha-pjlink-ir/releases/tag/v1.0.0) и распакуйте в каталог конфигурации Home Assistant. Должен получиться путь `/config/custom_components/pjlink_ir/manifest.json`.
2. Перезапустите Home Assistant.
3. Включите проектор штатным пультом. В «Настройки → Устройства и службы → Добавить интеграцию» найдите **Panasonic Projector**.
4. Введите адрес проектора, порт (обычно 4352) и пароль PJLink. Производитель и модель читаются с проектора.
5. Выберите ИК-передатчик и укажите имя устройства и команды. Для Broadlink и Xiaomi IR, например, `panasonic_projector` / `power_on`. В других интеграциях поле устройства можно оставить пустым, если они его не используют. Имена готовых команд нужно брать из настроек передатчика: общего стандартного списка кодов Home Assistant не предоставляет.
6. Если команды нет, выберите «Обучить включению сейчас» и следуйте инструкциям. При ошибке обучение можно повторить. После завершения мастер попросит проверить результат: часть передатчиков не возвращает ошибку обучения в вызов сервиса.
7. Убедитесь, что включение из сна работает, затем отключите старую запись штатного PJLink, чтобы избежать дублирования управления. Автоматизации переведите на новую сущность медиаплеера.

Интеграция устанавливается через HACS как пользовательский репозиторий. Она не заменяет файлы штатного PJLink и создаёт собственные сущности.

## Поведение питания

При включении интеграция читает питание по PJLink. Если проектор уже включён или прогревается — повторной команды нет. Если доступен в ожидании — одна команда PJLink Power On. Если TCP-соединение установить не удалось — одна ИК-команда, затем ожидание подтверждения включения/прогрева по PJLink до заданного срока (15–300 секунд).

Ошибка аутентификации, некорректный ответ или потеря ответа после соединения не запускают ИК-команду. При охлаждении включение отклоняется. После неопределённого результата команды не повторяются автоматически; повторные одновременные запросы сериализуются. Короткая блокировка после тайм-аута препятствует немедленной повторной отправке ИК.

Без сети медиаплеер остаётся доступным для вызова включения; состояние питания — **неизвестно**. Это позволяет включить спящий проектор даже после перезапуска HA, не выдавая сетевой обрыв за подтверждённое выключение. Фаза охлаждения соответствует выключенному медиаплееру и отдельно указана в атрибуте `power_phase`.

Лучше обучать отдельную команду **Power On**. Для общей кнопки питания обязательно проверьте включение из сна: при сетевой неисправности переключающая команда может выключить уже работающий проектор. Во время мастера команды питания не отправляются; обучение записывает код принятого нажатия. Если указать существующие имена устройства/команды, передатчик может перезаписать их код.

## Проверки

Если устройство появилось без объектов, откройте страницу интеграции, меню записи проектора → «Скачать диагностику». Файл содержит состояние записи, зарегистрированные объекты, их привязку к устройству, загруженные платформы и контрольные суммы файлов интеграции. Пароль PJLink, адрес подключения, настройки передатчика и ИК-коды из конфигурации не выгружаются. Диагностика не отправляет проектору или передатчику команды.

Локальные сетевые тесты используют эмулятор на `127.0.0.1`; физических устройств не касаются. Результаты и ограничения — в `VALIDATION.md`. Совместимость с конкретным проектором и реальное ИК-обучение требуют проверки на оборудовании.

Источники: [штатный PJLink Home Assistant](https://github.com/home-assistant/core/tree/dev/homeassistant/components/pjlink), [действия remote](https://www.home-assistant.io/integrations/remote/), [образец Harman v0.5.0](https://github.com/ipmerlin/ha-harman-kardon-avr/releases/tag/v0.5.0).
