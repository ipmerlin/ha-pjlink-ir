# PJLink with IR Wake

Интеграция Home Assistant для проекторов PJLink, у которых в режиме ожидания отключается Ethernet. Включение из сна — через выбранный ИК-передатчик, остальное управление — через PJLink. Настройка через интерфейс, без YAML.

## Возможности

- Автоматическое чтение производителя `INF1`, модели `INF2` и имени `NAME` при подключении. Неподдерживаемые поля не блокируют настройку.
- Включение и выключение, выбор входа, отключение звука через PJLink Class 1.
- Выбор любой сущности `remote` из списка. Проверен контракт вызовов Broadlink и пользовательской интеграции Xiaomi IR; фактическая поддержка других передатчиков зависит от их стандартных действий `remote.send_command` / `remote.learn_command`.
- Обучение команде включения во время настройки для передатчиков с поддержкой `LEARN_COMMAND`. Коды хранятся в интеграции передатчика. Повторное обучение доступно через «Перенастроить».
- Отдельный диагностический датчик связи PJLink; опрос каждые 30 секунд.

## Установка через HACS

1. Откройте HACS → меню → «Пользовательские репозитории».
2. Добавьте `https://github.com/ipmerlin/ha-pjlink-ir`, категория **Integration**.
3. Установите **PJLink with IR Wake**. Для предварительной версии включите показ предварительных выпусков.
4. Перезапустите Home Assistant и добавьте **PJLink with IR Wake** в «Настройки → Устройства и службы».

## Установка из архива

1. Скачайте `pjlink_ir-0.1.0.zip` со [страницы релиза](https://github.com/ipmerlin/ha-pjlink-ir/releases/tag/v0.1.0) и распакуйте в каталог конфигурации Home Assistant. Должен получиться путь `/config/custom_components/pjlink_ir/manifest.json`.
2. Перезапустите Home Assistant.
3. Включите проектор штатным пультом. В «Настройки → Устройства и службы → Добавить интеграцию» найдите **PJLink with IR Wake**.
4. Введите адрес проектора, порт (обычно 4352) и пароль PJLink. Производитель и модель читаются с проектора.
5. Выберите ИК-передатчик и укажите имя устройства и команды. Для Broadlink и Xiaomi IR, например, `panasonic_projector` / `power_on`. В других интеграциях поле устройства можно оставить пустым, если они его не используют. Имена готовых команд нужно брать из настроек передатчика: общего стандартного списка кодов Home Assistant не предоставляет.
6. Если команды нет, выберите «Обучить включению сейчас» и следуйте инструкциям. При ошибке обучение можно повторить. После завершения мастер попросит проверить результат: часть передатчиков не возвращает ошибку обучения в вызов сервиса.
7. Убедитесь, что включение из сна работает, затем отключите старую запись штатного PJLink, чтобы избежать дублирования управления. Автоматизации переведите на новую сущность медиаплеера.

Интеграция устанавливается через HACS как пользовательский репозиторий. Она не заменяет файлы штатного PJLink и создаёт собственные сущности.

## Поведение питания

При включении интеграция читает питание по PJLink. Если проектор уже включён или прогревается — повторной команды нет. Если доступен в ожидании — одна команда PJLink Power On. Если TCP-соединение установить не удалось — одна ИК-команда, затем ожидание подтверждения включения/прогрева по PJLink до заданного срока (15–300 секунд).

Ошибка аутентификации, некорректный ответ или потеря ответа после соединения не запускают ИК-команду. При охлаждении включение отклоняется. После неопределённого результата команды не повторяются автоматически; повторные одновременные запросы сериализуются. Короткая блокировка после тайм-аута препятствует немедленной повторной отправке ИК.

Без сети медиаплеер остаётся доступным для вызова включения; состояние питания — **неизвестно**. Это позволяет включить спящий проектор даже после перезапуска HA, не выдавая сетевой обрыв за подтверждённое выключение. Фаза охлаждения соответствует выключенному медиаплееру и отдельно указана в атрибуте `power_phase`.

Лучше обучать отдельную команду **Power On**. Для общей кнопки питания обязательно проверьте включение из сна: при сетевой неисправности переключающая команда может выключить уже работающий проектор. Во время мастера команды питания не отправляются; обучение записывает код принятого нажатия. Если указать существующие имена устройства/команды, передатчик может перезаписать их код.

## Проверки

Локальные сетевые тесты используют эмулятор на `127.0.0.1`; физических устройств не касаются. Результаты и ограничения — в `VALIDATION.md`. Совместимость с конкретным проектором и реальное ИК-обучение требуют проверки на оборудовании.
